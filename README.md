# Mikee’s Fruit Farm – Pick Your Own

A full-stack web platform for booking fruit-picking experiences, online payments, and event registration.

🌐 **Live Demo:** [https://pick-fresh-harvest.base44.app](https://pick-fresh-harvest.base44.app)

## Overview
This project includes a Node.js + Express backend and a React/Next.js frontend hosted on AWS Lightsail.
